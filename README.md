# La Súper Liga 2027

App web (PWA) en **HTML + CSS + TypeScript + Vite**, sin frameworks. Reconstrucción completa de la app anterior.

```bash
npm install
npm run dev        # desarrollo
npm run build      # producción (dist/)
npm run typecheck
```

Sin configurar nada arranca en **modo local** con datos de ejemplo. Con `.env` y las migraciones de `supabase/migrations/` usa la nube.

📚 Documentación en español: [`docs/README.md`](docs/README.md) — empezá por **customization.md** ("¿dónde cambio X?").
