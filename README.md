# La Súper Liga 2027

App web (PWA) en **HTML + CSS + JavaScript** puro (módulos ES), sin frameworks y **sin compilación**: lo que editás es lo que corre.

- Abrila con cualquier servidor estático (Vercel, GitHub Pages, `python -m http.server`).
- Sin configurar nada arranca en **modo local** con datos de ejemplo. Con tu URL y clave anon de Supabase en `src/core/config.js` y las migraciones de `supabase/migrations/` usa la nube.

📚 Documentación en español: [`docs/README.md`](docs/README.md) — empezá por **customization.md** ("¿dónde cambio X?") y **development.md** (cómo publicar y probar).
